강의 자료 편집기

홈페이지 Lecture 메뉴의 내용을 편집하고 비밀번호로 암호화합니다. 모든 작업은 이 브라우저 안에서만 이루어지고, 비밀번호와 원문은 어디에도 전송·저장되지 않습니다.

1. 현재 내용 불러오기

지금 사이트에 올라가 있는 content.enc.json을 현재 비밀번호로 엽니다.

2. 내용 편집

항목마다 제목(한/영), 날짜, 링크, 메모를 입력하세요. 링크가 없으면 비워 두면 됩니다. 영어 칸을 비우면 한국어가 그대로 보입니다.

3. 암호화해서 저장

비밀번호를 바꾸지 않으려면 현재 비밀번호를 그대로 입력하세요. 짧은 비밀번호는 뚫릴 수 있으니 10자 이상, 단어 여러 개를 이어 쓰는 방식을 권장합니다.

  1. 다운로드된 content.enc.json을 저장소의 lecture 폴더에 덮어씁니다.
  2. GitHub Desktop에서 커밋하고 Push origin을 누릅니다.
  3. 1~2분 뒤 사이트의 Lecture 메뉴에서 새 비밀번호로 확인합니다.
