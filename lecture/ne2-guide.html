핵심 개념

위에서 아래로 읽으면 유도의 흐름이 됩니다
§5.1 중성자속과 반응률

φ = nv 는 '길이의 합'

중성자속은 단위 부피 안 중성자들이 1초 동안 그리는 궤적 길이의 합입니다. 여기에 거시단면적(1 cm 당 반응 확률)을 곱하면 반응률이 됩니다.

$$\phi=nv,\qquad F=\Sigma\phi\ \ [\text{반응}/\text{cm}^3\text{s}]$$
흔한 오해 φ는 방향이 없는 스칼라입니다. 방향을 가진 순흐름은 중성자류 J입니다.
§5.2 Fick의 법칙

많은 곳에서 적은 곳으로

중성자속이 불균일하면 높은 곳에서 낮은 곳으로 순흐름이 생깁니다. 비례상수가 확산계수 D이며, 비등방 산란은 수송단면적으로 반영합니다.

$$\mathbf J=-D\nabla\phi,\qquad D=\frac{1}{3\Sigma_{tr}},\quad \Sigma_{tr}=\Sigma_t-\bar\mu\Sigma_s$$
적용 한계 강흡수체 근처, 진공경계 바로 옆, 선원 근처(수 평균자유행로 이내)에서는 부정확합니다.
§5.3–5.4 연속방정식 → 확산방정식

축적 = 생성 − 흡수 − 누설

임의의 부피에 중성자 수지를 세우고 Fick의 법칙을 넣으면 확산방정식이 됩니다. 정상상태에서는 확산길이 L 하나로 정리됩니다.

$$\frac{1}{v}\frac{\partial\phi}{\partial t}=D\nabla^2\phi-\Sigma_a\phi+S$$
$$\nabla^2\phi-\frac{\phi}{L^2}=-\frac{S}{D},\qquad L^2=\frac{D}{\Sigma_a}$$
§5.5 경계조건

세 가지 경계

① 물질 경계 : φ와 법선 방향 J가 연속. ② 대칭면 : dφ/dn = 0. ③ 진공 경계 : 실제 표면 바깥 외삽거리 d 에서 φ = 0.

$$d\simeq0.71\lambda_{tr}=2.13D$$
흔한 오해 외삽경계는 수학적 장치입니다. 실제 표면의 중성자속은 0이 아닙니다.
§5.6–5.7 대표해와 확산길이

L은 '한 번'이 아니라 '여러 번' 산란한 거리

평면원은 e^(−|x|/L), 점원은 e^(−r/L)/r 형태로 감소합니다. 열중성자가 태어난 곳에서 흡수될 때까지의 평균제곱 직선거리는 6L²입니다.

$$\phi(r)=\frac{S}{4\pi Dr}e^{-r/L},\qquad \overline{r^2}=6L^2$$
§5.8–5.10 감속과 군 이론

고속 → 열 : 감속면적 τ

에너지를 몇 개 군으로 나누고 군마다 확산방정식을 세웁니다. 2군에서는 고속군의 제거(감속)가 열군의 선원이 됩니다. τ는 감속 동안, L²는 열중성자 상태에서의 퍼짐입니다.

$$-D_2\nabla^2\phi_2+\Sigma_{a2}\phi_2=\Sigma_{r1}\phi_1,\qquad M^2=\tau+L^2$$

무엇을 배우나

단일 빔에서는 세기 I = nv 와 반응률 F = ΣI 를 정의했습니다. 원자로 안에서는 중성자가 모든 방향으로 날아다니므로, 방향을 구분하지 않고 단위 부피 안 모든 중성자의 속력을 더한 φ = nv 를 씁니다. 표적 핵 입장에서는 빔이 어느 방향에서 오든 상관없기 때문에 반응률은 여전히 Σφ 입니다.

물리적 의미

  • φ 는 1 cm³ 안의 중성자들이 1초 동안 그리는 궤적 길이의 합 [cm/cm³·s].
  • Σ 는 1 cm 이동당 반응 확률이므로 Σ × (총 이동거리) = 반응 수.
  • 에너지 분포가 있으면 \(F=\int\Sigma(E)\phi(E)\,dE\). 1/v 흡수체의 열중성자에서는 \(F=\frac{\sqrt\pi}{2}g_a(T)\Sigma_a(E_0)\left(\frac{T_0}{T}\right)^{1/2}\phi_T\).

핵심 결과

$$\phi=nv,\qquad F=\Sigma\phi,\qquad P=E_R\Sigma_f\phi V$$

방 한쪽에 향수를 뿌리면 시간이 지나 방 전체로 퍼지죠. 향 분자가 '저쪽으로 가야지' 하고 움직이는 게 아니라 제멋대로 움직이는데, 진한 쪽에 분자가 더 많으니 결과적으로 진한 쪽 → 옅은 쪽 흐름이 생기는 거예요. 중성자도 똑같아요. 식의 음(−) 부호는 '내리막 방향으로 흐른다'는 뜻이고, D는 얼마나 잘 퍼지는지(한 번에 멀리 날수록 큼)를 나타내요.

무엇을 배우나

어떤 면을 통과하는 중성자는 그 면 근처에서 마지막으로 산란된 중성자들입니다. 위쪽에서 내려오는 것(J₋)과 아래에서 올라가는 것(J₊)을 각각 적분하면, 중성자속이 큰 쪽에서 더 많이 넘어오므로 순흐름은 기울기에 비례합니다.

유도 흐름

  1. dV 에서 산란률 Σsφ dV, 등방 산란 → 면 dA 를 향할 확률 cosθ dA/(4πr²).
  2. 가는 길에 감쇠 e−Σtr, φ 를 원점 근처에서 Taylor 전개 (1차까지).
  3. J₋ − J₊ 를 계산 → \(J_z=-\frac{\lambda_s}{3}\frac{d\phi}{dz}\).
  4. 실험실계 비등방 산란 보정 : λs → λtr = λs/(1−μ̄), μ̄ = 2/(3A).

핵심 결과

$$\mathbf J=-D\nabla\phi,\qquad D=\frac{\lambda_{tr}}{3}=\frac{1}{3\Sigma_{tr}},\qquad J_\pm=\frac{\phi}{4}\mp\frac{D}{2}\frac{d\phi}{dx}$$

시험 포인트

유도에서 쓴 가정 다섯 가지 — 무한매질, 등방 산란(→ 보정), 약흡수 Σa ≪ Σs, 중성자속이 천천히 변함, 선원 · 경계에서 수 λ 이상 떨어짐. 수소(A = 1)는 μ̄ = 2/3 로 보정이 큽니다.

§5.3연속방정식임의 부피에 대한 중성자 수지
쉽게 말하면

통장 잔고를 생각해 보세요. 잔고 변화 = 입금 − 출금 − 수수료. 중성자 수도 변화율 = 생성 − 흡수 − 누설(표면으로 새어 나감)이에요. 산란은 중성자의 방향만 바꿀 뿐 개수는 그대로라서 장부에 나오지 않아요. 이 식은 '세기'만 했기 때문에 근사가 하나도 없다는 점이 중요해요.

무엇을 배우나

부피 V 안 중성자 수의 변화율 = 생성률 − 흡수율 − 표면을 통한 누설률. 표면적분을 발산정리로 부피적분으로 바꾸면 미분형이 됩니다. 산란은 중성자 수를 바꾸지 않으므로(1군 기준) 나타나지 않습니다.

핵심 결과

$$\frac{\partial n}{\partial t}=s-\Sigma_a\phi-\nabla\cdot\mathbf J$$

정상상태 : \(\nabla\cdot\mathbf J+\Sigma_a\phi-s=0\). 누설 = ∇·J 라는 점이 핵심입니다.

시험 포인트

이 식 자체는 근사가 없습니다. 근사는 다음 절에서 J 에 Fick 법칙을 넣을 때 들어옵니다.

§5.4확산방정식연속방정식 + Fick 법칙
쉽게 말하면

연속방정식의 '누설' 칸을 Fick 법칙으로 채우면 φ 하나만 남는 방정식이 돼요. ∇²φ는 'φ 그래프가 얼마나 휘었나'예요. 위로 볼록하게 많이 휠수록 주변으로 많이 새어 나간다는 뜻이죠. 열전도 방정식과 모양이 똑같아서, 열전달에서 배운 풀이를 그대로 가져다 쓸 수 있어요.

무엇을 배우나

D 가 공간적으로 일정하면 ∇·J = −D∇²φ. 이를 대입하면 φ 하나에 대한 2계 편미분방정식이 됩니다. 열전도의 \(\nabla^2T+q'''/k=0\) 과 같은 꼴이라 해법도 같습니다.

핵심 결과

$$D\nabla^2\phi-\Sigma_a\phi+s=\frac1v\frac{\partial\phi}{\partial t}\ \xrightarrow{\ \text{정상}\ }\ \nabla^2\phi-\frac{1}{L^2}\phi=-\frac sD$$

라플라시안 : 직교 \(\partial_x^2+\partial_y^2+\partial_z^2\), 구 \(\frac{1}{r^2}\frac{d}{dr}r^2\frac{d}{dr}\), 원통 \(\frac1r\frac{d}{dr}r\frac{d}{dr}+\partial_z^2\).

시험 포인트

문제마다 좌표계를 고르고, 일반해 (cosh/sinh, e±r/L/r, I₀/K₀) 를 쓴 뒤 경계조건으로 상수를 정하는 3단계가 정형입니다.

§5.5경계조건미분방정식의 해를 하나로 정하는 조건들
쉽게 말하면

미분방정식은 해가 무수히 많아요. 그중 '진짜 해'를 고르는 규칙이 경계조건이에요. ① φ는 음수나 무한대가 될 수 없고, ② 두 물질이 맞닿은 곳에서는 중성자가 갑자기 생기거나 사라지지 않으니 φ와 J가 이어져야 하고, ③ 바깥이 진공이면 되돌아오는 중성자가 없어요. ③을 계산하기 쉽게 '표면보다 조금 바깥(d)에서 φ = 0'으로 바꿔 쓰는 게 외삽거리 트릭이에요.

무엇을 배우나

  • 물리적 조건 : φ 는 실수 · 음이 아니고 유한해야 합니다 (선원점 제외). → 무한매질에서 e+x/L 항 제거.
  • 물질 경계 : φA = φB, \(D_A\frac{d\phi_A}{dx}=D_B\frac{d\phi_B}{dx}\) (J 연속). D 가 다르면 기울기는 불연속.
  • 진공 경계 : 들어오는 중성자가 없음 J₋ = 0 → 선형 외삽하면 표면 밖 d 에서 0. 수송이론 결과 d = 0.71λtr.
  • 선원 조건 : 평면원 \(\lim_{x\to0}J=S/2\), 점원 \(\lim_{r\to0}4\pi r^2J=S\).
  • 대칭 : 대칭면에서 dφ/dx = 0.

핵심 결과

$$\phi(\tilde a)=0,\qquad \tilde a=a+d,\quad d=0.71\lambda_{tr}=2.13D$$

시험 포인트

d 는 보통 노심 크기(수십 ~ 수백 cm) 대비 작아(물 ≈ 0.4 cm) 대형로에서는 무시하기도 하지만, 소형 계(예 : 작은 실험용 집합체)에서는 반드시 포함합니다.

§5.6확산방정식의 해 (비증배 매질)평면원 · 점원 · 유한 평판 · 중첩
쉽게 말하면

풀이 순서는 항상 같아요: 좌표계 고르기 → 일반해 쓰기 → 말이 안 되는 항 지우기 → 경계·선원 조건으로 상수 정하기. 점원 해에서 1/r 은 '멀어질수록 넓은 구면에 나눠 담겨서' 줄어드는 부분이고, e−r/L 은 '가는 도중 흡수돼서' 줄어드는 부분이에요. 진공 속 빛이라면 1/r² 만 있었을 텐데, 매질이 흡수하니 지수 감쇠가 하나 더 붙는 거죠.

대표 문제

  1. 무한 평면원 : x ≠ 0 에서 φ'' − φ/L² = 0 → \(\phi=Ae^{-|x|/L}\). 선원 조건으로 A = SL/2D.
  2. 무한 매질 점원 : φ = w/r 치환으로 평판 문제와 같아짐 → \(\phi=\frac{S e^{-r/L}}{4\pi Dr}\).
  3. 유한 평판 (두께 2a, 중앙 평면원) : \(\phi=\frac{SL}{2D}\frac{\sinh[(\tilde a-|x|)/L]}{\cosh(\tilde a/L)}\).
  4. 여러 선원 : 방정식이 선형이라 각 선원의 해를 더함 (중첩).

핵심 결과

$$\phi_{plane}=\frac{SL}{2D}e^{-|x|/L},\qquad \phi_{point}=\frac{S}{4\pi D}\frac{e^{-r/L}}{r}$$

시험 포인트

점원 해의 1/r 은 '기하학적 퍼짐', e−r/L 은 '흡수에 의한 감쇠'. 해를 구한 뒤 흡수율 \(\int\Sigma_a\phi\,dV=S\) 로 검산하는 습관이 좋습니다.

§5.7확산길이L 의 물리적 의미와 측정
쉽게 말하면

L은 열중성자가 '흡수되기 전까지 얼마나 멀리 가는가'의 눈금이에요. 한 번 날아가는 거리가 아니라, 수십~수백 번 튕기며 지그재그로 간 끝에 출발점에서 직선으로 떨어진 거리예요. 물은 흡수가 꽤 있어서 L ≈ 3 cm로 짧고, 흑연은 흡수가 거의 없어 약 50 cm나 돼요. L이 길수록 노심 밖으로 새기 쉬워서 원자로를 더 크게 만들어야 해요.

무엇을 배우나

점원에서 r ~ r+dr 껍질에서 흡수될 확률 \(p(r)dr=\frac{r}{L^2}e^{-r/L}dr\). 이를 이용해 흡수 지점까지의 평균제곱거리를 구하면 6L² 입니다. 즉 L 은 '열중성자가 흡수되기 전까지 직선거리로 퍼지는 정도'를 나타냅니다.

핵심 결과

$$\overline{r^2}=\int_0^\infty r^2p(r)\,dr=6L^2,\qquad L^2=\frac{D}{\Sigma_a}=\frac{\lambda_{tr}\lambda_a}{3}$$

대표값 (열중성자) : H₂O 2.85 cm, D₂O 약 100 – 170 cm (순도 의존), Be 21 cm, 흑연 50 – 59 cm.

시험 포인트

측정 : 긴 기둥 한쪽에 선원을 두고 축방향 φ 의 지수감쇠 기울기로 L 을 구함 (exponential pile). L ∝ Σa−1/2 — 연료를 섞으면 L² = LM²(1−f) 로 줄어듭니다 (6장).

§5.8군확산법 (Group-Diffusion)에너지 의존성을 몇 개의 군으로 이산화
쉽게 말하면

중성자는 2 MeV로 태어나 0.025 eV까지, 에너지가 거의 1억 분의 1로 줄어요. 에너지마다 단면적이 완전히 달라서 D, Σ 하나로 묶기 어렵죠. 그래서 에너지를 구간(군)으로 잘라 각 구간을 한 종류의 중성자처럼 다뤄요. 학생을 학년별로 나눠 학년마다 다른 시간표를 주는 것과 비슷해요. 윗학년(고속군)에서 '졸업'한 중성자가 아랫학년(열군)으로 들어오는 게 군간 산란이에요.

무엇을 배우나

중성자는 2 MeV 로 태어나 0.025 eV 까지 감속되므로 단면적이 에너지에 따라 크게 변합니다. 에너지 축을 G 개 구간으로 나누고, 각 구간의 반응률을 보존하도록 평균한 '군정수'로 군마다 확산방정식을 씁니다. 군은 높은 에너지부터 1, 2, … 로 번호를 매깁니다.

핵심 결과

$$-D_g\nabla^2\phi_g+\Sigma_{ag}\phi_g+\Sigma_{Rg}\phi_g=\sum_{h<g}\Sigma_{s,h\to g}\phi_h+\chi_g S$$

ΣRg : 군 g 밖으로 산란되어 나가는 '제거' 단면적. χg : 핵분열 중성자가 군 g 에 태어날 분율.

시험 포인트

군정수는 \(\Sigma_{x,g}=\frac{1}{\phi_g}\int_g\Sigma_x(E)\phi(E)dE\) — 정확하게 평균하려면 φ(E) 를 이미 알아야 한다는 순환 문제가 있어 근사 스펙트럼을 씁니다.

§5.9열중성자 확산열군 정수 구하기
쉽게 말하면

감속이 끝난 중성자는 주변 원자들과 열평형을 이뤄, 온도에 맞는 속도 분포(Maxwell 분포)를 가져요. 상온의 공기 분자들이 제각각 다른 속도로 움직이는 것과 같아요. 흡수단면적은 대체로 느릴수록 커지는데(1/v), 온도가 오르면 중성자가 평균적으로 빨라져서 평균 흡수단면적이 줄어요. 그래서 열군 단면적에는 온도 보정이 붙어요.

무엇을 배우나

열군은 Maxwell 분포 스펙트럼으로 평균합니다. 1/v 흡수체면 평균 흡수단면적이 0.0253 eV 값에 √π/2 · (T₀/T)1/2 을 곱한 것이 되고, 비-1/v 핵종은 g 인자로 보정합니다. 확산계수는 온도 · 밀도 의존성을 따로 보정합니다.

핵심 결과

$$\bar\Sigma_a=\frac{\sqrt\pi}{2}g_a(T)\Sigma_a(E_0)\left(\frac{T_0}{T}\right)^{1/2},\qquad \bar D=\bar D_0\frac{\rho_0}{\rho}\left(\frac{T}{T_0}\right)^m$$

열확산방정식 : \(\bar D\nabla^2\phi_T-\bar\Sigma_a\phi_T+s_T=0\), \(L_T^2=\bar D/\bar\Sigma_a\).

시험 포인트

운전 온도에서 물 밀도가 줄면 D ↑, Σa ↓ → L 이 커집니다. 예 : 물 L ∝ (1/ρ)(T/T₀)(1+m)/2.

§5.102군 감속 계산과 Fermi age고속군 제거가 열군의 선원
쉽게 말하면

고속 중성자는 '느려지는 동안' 한 번 퍼지고, 열중성자가 된 뒤 '흡수될 때까지' 또 한 번 퍼져요. 첫 번째 퍼짐의 크기가 τ (Fermi age), 두 번째가 L²이에요. 고속군에서 빠져나간(감속된) 중성자가 곧 열군의 선원이 되니 두 방정식이 사슬처럼 이어지죠. 물은 수소가 한두 번 충돌에 에너지를 크게 빼앗아 τ가 작고, 흑연은 탄소가 무거워 백 번 넘게 부딪혀야 해서 τ가 커요.

유도 흐름

  1. 고속군 : \(D_1\nabla^2\phi_1-\Sigma_1\phi_1+s=0\), Σ₁ = 고속군 제거(감속) 단면적.
  2. 열군 : 선원이 Σ₁φ₁ → \(D_2\nabla^2\phi_2-\Sigma_{a2}\phi_2+\Sigma_1\phi_1=0\).
  3. 고속군에도 '확산길이' 가 생김 : \(\tau_1=D_1/\Sigma_1\) = 2군 Fermi age.
  4. 점원 해 : 열중성자 '탄생' 위치 분포의 평균제곱거리 \(\overline{r_s^2}=6\tau\).

핵심 결과

$$\tau=\frac{D_1}{\Sigma_1},\qquad M^2=\tau+L_T^2,\qquad \overline{r^2}_{\text{탄생→흡수}}=6M^2$$

τ (cm²) : H₂O 27, D₂O 131, Be 102, 흑연 368.

시험 포인트

쉽게 말하면

5장에서 선원 S는 '바깥에서 넣어 주는 것'이었어요. 원자로에서는 선원이 핵분열, 즉 중성자가 만든 중성자예요. 그러면 'φ가 φ를 만드는' 구조가 되어, '어떤 모양의 φ라야 자기 자신을 정확히 다시 만들어 낼까?'를 묻는 고유치 문제가 돼요. 정리하면 ∇²φ + B²φ = 0 — 'φ의 휜 정도가 B²로 정해진 함수'를 찾는 문제예요.

무엇을 배우나

  1. \(D\nabla^2\phi-\Sigma_a\phi+\nu\Sigma_f\phi=\frac1v\frac{\partial\phi}{\partial t}\).

핵심 결과

$$\nabla^2\phi+B^2\phi=0,\qquad B^2=\frac{k_\infty-1}{L^2}$$

§6.41군 임계방정식k 를 누설로 쓰고 임계 크기 · 조성을 구한다
쉽게 말하면

k를 '한 세대 동안의 손익계산서'로 보면 쉬워요. 수입은 핵분열로 생긴 중성자 νΣfφ, 지출은 흡수 Σaφ와 누설 DB²φ. k = 수입 ÷ 지출이에요. 무한히 큰 원자로라면 누설이 없으니 k = k∞, 실제로는 '새지 않을 확률' PL을 곱해 k = k∞PL이 돼요. 문제는 보통 두 가지예요 — 재료가 주어졌을 때 임계 크기 구하기, 크기가 주어졌을 때 필요한 연료 농도 구하기.

기본모드에서 ∇²φ = −B²φ 이므로 누설률 = DB²φ. 증배계수를 '생성 / (흡수 + 누설)' 로 정의하면 k = k∞ × 비누설확률 이 됩니다. 재료로 Bm² 를, 형상으로 Bg² 를 계산해 비교합니다.

  • 크기 구하기 : 조성(k∞, L²) 주어짐 → Bm² → 형상식으로 Rc.

네 인자의 의미

  • η = νσf/σa (연료) : 연료에 흡수된 열중성자 1개당 다음 세대 고속중성자. ²³⁵U 2.065.
  • f = ΣaF/Σa : 흡수 중 연료가 차지하는 비율.
  • p : 감속 중 ²³⁸U 공명흡수를 피할 확률.
  • ε : 고속 핵분열(²³⁸U)로 늘어나는 분율, 균질로에서는 ≈ 1.

$$k=\frac{k_\infty e^{-B^2\tau}}{1+L^2B^2}\simeq\frac{k_\infty}{1+M^2B^2},\qquad L^2=L_M^2(1-f)$$

§6.6반사체가 있는 원자로반사체 절약과 중성자속 평탄화
쉽게 말하면

노심 밖으로 나가는 중성자 일부를 되돌려 보내는 거울이 반사체예요. 물·흑연·베릴륨처럼 흡수는 적고 산란은 잘하는 물질을 써요. 반사체가 있으면 누설이 줄어 같은 재료로 더 작은 노심이 임계가 되고, 가장자리 φ가 올라가 출력 분포도 평평해져요. '반사체 덕분에 줄일 수 있는 노심 두께'가 δ(반사체 절약)예요.

유도 흐름 (1군 반사 평판)

  1. 노심(|x| < a/2) : φc'' + B²φc = 0 → \(A\cos Bx\).
  2. 반사체 (비증배) : φr'' − φr/Lr² = 0 → \(C\sinh[(a/2+b-|x|)/L_r]\) (외측 경계 0).
  3. 경계 x = a/2 에서 φ 와 J 연속 → 임계방정식 \(D_cB\tan\frac{Ba}{2}=\frac{D_r}{L_r}\coth\frac{b}{L_r}\).
  4. 맨 노심 대비 줄어든 두께 = 2δ.

먼저 예측

예제로 확인

구형 원자로의 임계 반지름

k∞ = 1.30, M² = 30 cm² 인 균질 노심을 구로 만들 때 임계 반지름(외삽)은?

$$B_m^2=\frac{k_\infty-1}{M^2}=\frac{0.30}{30}=0.01\ \text{cm}^{-2},\qquad R_c=\frac{\pi}{B_m}=\frac{\pi}{0.1}=31.4\ \text{cm}$$

같은 재료로 H = D 원통이면 \(R_c=\sqrt{2.405^2+(\pi/2)^2}/B_m=28.7\) cm. 위의 계산기로 확인해 보세요.

구형 원자로의 중성자속을 출력으로 정규화

\(\phi=A\sin(\pi r/R)/r\) 에서 상수 A는 노심 출력으로 정합니다.

$$P=E_R\Sigma_f\int_0^R\phi\,4\pi r^2dr=4R^2E_R\Sigma_fA\ \Rightarrow\ A=\frac{P}{4R^2E_R\Sigma_f}$$

형상은 버클링이, 크기는 출력이 정합니다 — 임계 계산만으로는 φ의 절대값이 나오지 않습니다.

Q1 원자로가 커지면 Bg²와 누설확률은?

구. 표면적/부피 비가 가장 작아 같은 부피에서 Bg² 가 가장 작습니다. 실제 원자로는 제작 · 냉각 때문에 H ≈ D 원통을 씁니다 (원통 중에서는 H/D ≈ 0.92 가 최적).

핵분열 중성자의 β (²³⁵U 0.65 %) 는 핵분열생성물(선행핵, 예 ⁸⁷Br)이 β붕괴한 뒤 방출됩니다. 반감기에 따라 6군으로 묶고, 군마다 선행핵 농도 Ci 의 방정식을 세웁니다.

방정식

$$\frac{dn}{dt}=\frac{\rho-\beta}{\Lambda}n+\sum_i\lambda_iC_i,\qquad \frac{dC_i}{dt}=\frac{\beta_i}{\Lambda}n-\lambda_iC_i$$

평균 세대시간 \(\bar l=(1-\beta)l_p+\sum\beta_i(t_i+l_p)\approx\sum\beta_it_i=0.0848\) s → 즉발만 있을 때보다 약 850배 깁니다.

§7.2 ③Inhour 방정식과 원자로 주기ρ 와 T 의 관계 (Fig. 7.2)
쉽게 말하면

'반응도 ρ를 넣으면 출력이 몇 초마다 e배가 되나(주기 T)?'에 답하는 식이 Inhour 방정식이에요. 식보다 그래프(Fig. 7.2)로 기억하면 쉬워요. ρ가 작으면 T가 길고(분 단위, 지발중성자가 주도), ρ가 β에 가까워지면 T가 급격히 짧아져요. 운전원이 실제로 다루는 범위는 T가 수십 초 이상인 쪽이에요.

유도 흐름

  1. n, Ci ∝ eωt 를 대입.
  2. Ci 를 소거 → ω 에 대한 7차 대수방정식 (inhour).
  3. ρ > 0 : 양의 근 1개 (ω₁) + 음의 근 6개 → 시간이 지나면 \(e^{\omega_1t}\) 만 남음 = 안정 주기 T = 1/ω₁.
  4. ρ < 0 : 모든 근 음수, 가장 작은 절댓값 근이 지배 → T ≥ 1/λ₁ = 80 s 의 하한.

근사식

$$\rho\ll\beta:\ T\simeq\frac{\sum\beta_it_i}{\rho}=\frac{0.0848}{\rho},\qquad \rho>\beta:\ T\simeq\frac{l_p}{\rho-\beta}$$

시험 포인트

§7.2 ④즉발임계 · 즉발도약 · Scram계단 반응도 직후의 순간 변화
쉽게 말하면

반응도를 계단처럼 확 바꾸면, 즉발중성자는 그 자리에서 새 균형으로 '점프'하지만 선행핵은 아직 예전 양 그대로예요. 그래서 출력이 먼저 β/(β−ρ)배로 툭 뛰거나 떨어지고(즉발도약·강하), 그 뒤 주기 T로 천천히 변해요. 아무리 큰 음의 반응도를 넣어도(scram), 가장 오래 사는 선행핵(반감기 55.7초)이 중성자를 계속 내놓으니 출력은 −80초 주기보다 빨리 줄지 못해요.

무엇을 배우나

  • 즉발임계 ρ = β : 즉발중성자만으로 kp = k(1−β) = 1. 이를 넘으면 주기가 lp 수준.

  • Scram : 큰 음의 반응도 → 즉시 β/(β−ρ) 수준으로 떨어진 뒤 −80 s 주기로 감소 (55.7 s 군이 마지막까지 남음).

핵심 결과

$$\frac{\phi_1}{\phi_0}=\frac{\beta(1-\rho)}{\beta-\rho}\qquad(\text{1군 근사 : }\frac{\beta}{\beta-\rho})$$

시험 포인트

§7.3제어봉과 화학적 shim반응도를 바꾸는 공학적 수단
쉽게 말하면

반응도를 사람이 조절하는 두 손잡이예요. 제어봉은 빠르고 국부적이라 기동·정지·급변에 쓰고, 냉각수에 녹인 붕소(화학적 shim)는 느리지만 노심 전체에 고르게 작용해서 연소로 천천히 변하는 반응도를 맞추는 데 써요. 제어봉 가치는 φ가 큰 노심 중앙에서 가장 커서, 같은 10 cm를 빼도 위치에 따라 효과가 전혀 달라요(S자 적분 가치 곡선).

제어봉 가치

  1. 중심 제어봉 (원통 노심) : 제어봉 표면을 흑체 경계로 두고 수정 1군 이론으로 \(B^2\) 변화 계산.
  2. \(\rho_w=\frac{(B^2-B_0^2)M_T^2}{1+B_0^2M_T^2}\) — B₀² : 제어봉 없을 때.
  3. 부분 삽입 : 섭동이론으로 가치 ∝ ∫φ², cos² 분포에서 적분 → S자 곡선.
  4. 여러 봉 : 상호 그림자 효과(shadowing)로 가치가 단순 합이 아님.

핵심 결과

$$\rho_w(x)=\rho_w(H)\left[\frac xH-\frac{1}{2\pi}\sin\frac{2\pi x}{H}\right],\qquad \rho_w=1.92C\times10^{-3}(1-f_0)$$

붕소(화학적 shim)의 장단점

  • 장점 : 노심 전체에 균일 → 출력 분포를 왜곡하지 않음, 느린 연소 보상에 적합.
  • 단점 : 빠른 조절 불가, 농도가 높으면 감속재 온도계수를 양으로 만들 수 있음 (온도 ↑ → 물 팽창 → 붕소도 빠져나감).
  • 가연성 독물 (Gd₂O₃, B₄C 봉) 로 초기 붕소량을 줄입니다.

시험 포인트

미분가치 dρ/dx 는 중앙에서 최대 → 중앙 근처 인출이 가장 위험 (Problem 7.28). 붕소 ppm 과 H₃BO₃ g/L 환산 (Ex. 7.12).

§7.4온도가 반응도에 미치는 영향Doppler, 감속재 밀도, 음의 계수와 안정성
쉽게 말하면

좋은 원자로는 '뜨거워지면 스스로 출력이 줄도록' 만들어져요. 연료가 뜨거워지면 ²³⁸U 원자핵이 더 활발히 떨려 공명 흡수가 넓어지고(Doppler 효과) → p ↓ → k ↓. 냉각재가 뜨거워져 밀도가 줄면 감속이 약해져 → 역시 k ↓. 이렇게 음의 온도계수는 저절로 걸리는 브레이크예요. 단, 붕소를 많이 녹여 두면 물이 팽창할 때 붕소도 함께 빠져나가 감속재 계수가 양(+)이 될 수 있어 주의해요.

무엇을 배우나

\(\alpha_T=\frac{d\rho}{dT}\simeq\frac{1}{k}\frac{dk}{dT}\). α < 0 이면 출력 ↑ → 온도 ↑ → ρ ↓ 로 스스로 안정화합니다. 연료 온도는 출력에 즉시 반응하고(즉발 계수), 감속재는 열전달 지연 후 반응합니다(지연 계수).

성분별

  • Doppler (연료) : 연료 원자의 열운동으로 공명 피크가 넓어짐 → 자기차폐 감소 → 공명흡수 ↑ → p ↓. \(\alpha=-\frac{\beta_I}{2\sqrt T}\ln\frac{1}{p(300)}\).
  • 감속재 밀도 : 물 팽창 → 감속 · 흡수 감소 → p ↓ (감속 부족), f ↑ (물의 흡수 감소), 누설 ↑.
  • 스펙트럼 경화 : 열중성자 온도 ↑ → 1/v 흡수 감소, η 변화.
  • Void : BWR 에서 기포 ↑ → 감속 ↓ → 음의 반응도.

시험 포인트

Ex. 7.13 계산 흐름 (각 인자 미분 합산), 상온 → 운전온도 '온도 결손(temperature defect)' 만큼 잉여반응도가 필요하다는 설계 논리. 체르노빌(RBMK)의 양의 void 계수를 반례로 쓰는 문제가 자주 나옵니다.

§7.5핵분열생성물 독물¹³⁵Xe 와 ¹⁴⁹Sm
쉽게 말하면

핵분열 찌꺼기 중 ¹³⁵Xe는 열중성자를 엄청나게 잘 잡아먹는 '독'이에요. 운전 중에는 생성과 소멸(중성자 흡수로 타 없어짐)이 균형을 이뤄요. 그런데 원자로를 끄면 소멸이 멈추는데, 이미 쌓인 ¹³⁵I는 계속 Xe로 붕괴하니 Xe가 오히려 늘어나요 — 약 11시간 뒤 최대. 이때 잉여반응도가 부족하면 다시 켤 수 없어 하루 가까이 기다려야 해요(deadtime). ¹⁴⁹Sm은 안정 핵종이라 정지 후 쌓이기만 하고 사라지지 않아요.

생성 사슬

$$^{135}\text{Te}\xrightarrow{19\,\text{s}}{}^{135}\text{I}\xrightarrow{6.57\,\text{h}}{}^{135}\text{Xe}\xrightarrow{9.14\,\text{h}}{}^{135}\text{Cs},\qquad \sigma_{aX}=2.65\times10^6\ \text{b}$$
$$^{149}\text{Nd}\xrightarrow{1.7\,\text{h}}{}^{149}\text{Pm}\xrightarrow{53\,\text{h}}{}^{149}\text{Sm}\ (\text{안정}),\qquad \sigma_{aS}=4.1\times10^4\ \text{b}$$

유도 흐름 (Xe)

  1. \(\frac{dI}{dt}=\gamma_I\Sigma_f\phi-\lambda_II\), \(\frac{dX}{dt}=\gamma_X\Sigma_f\phi+\lambda_II-\lambda_XX-\sigma_{aX}\phi X\).
  2. 평형 : \(X_\infty=\frac{(\gamma_I+\gamma_X)\Sigma_f\phi}{\lambda_X+\sigma_{aX}\phi}\) → φ 가 크면 포화 (φ ≫ φX = λX/σaX).
  3. 정지 후 (φ = 0) : burnout 이 사라지고 I 붕괴는 계속 → 약 11 h 에 정점, 이후 감소.

Sm 과의 차이

  • 평형 Sm 반응도 \(-\gamma_P/\nu p\varepsilon\approx-0.44\%\) 로 중성자속과 무관.
  • 정지 후 Pm 이 모두 Sm 으로 → 증가해서 그대로 유지 (Sm 은 안정 핵이라 줄지 않음), 재기동 후 연소로만 감소.

시험 포인트

Xe 정점과 deadtime (위 실험실 2), 고출력일수록 정점이 큼, 대형로의 공간적 Xe 진동 (출력 분포가 수십 시간 주기로 출렁임).

§8.2원자로 내 열발생과 붕괴열q''' 의 크기 · 분포, 정지 후 남는 열
쉽게 말하면

열이 생기는 양은 핵분열이 일어나는 양, 즉 φ에 비례해요. 그래서 6장에서 구한 φ 모양(반지름 방향 J₀ × 높이 방향 cos)이 그대로 열 분포가 돼요 — 중앙이 가장 뜨겁고 가장자리는 덜 뜨거워요. 핵분열 에너지 200 MeV 중 약 180 MeV가 연료 안에서 열이 되고, 나머지는 바깥에 흩어지거나 중성미자로 빠져나가요. 원자로를 꺼도 쌓인 핵분열생성물이 붕괴하며 열을 계속 내는데, 이게 붕괴열이에요.

에너지는 어디에 쌓이나 (핵분열 1회 ≈ 200 MeV)

  • 핵분열 파편 운동에너지 ~168 MeV → 연료 안에서 즉시.
  • 즉발 γ, 중성자 감속 → 일부는 감속재 · 구조재.
  • β, γ 붕괴 (지연) → 연료 대부분, 정지 후에도 계속 = 붕괴열.
  • 중성미자 ~10 MeV → 손실. 연료에 쌓이는 몫 Ed ≈ 180 MeV.

유도 흐름

  1. \(q'''=E_d\Sigma_f\phi\), 원통 맨 노심 φ = A J₀ cos.
  2. 봉 n 개, 연료 반지름 a 로 연료 부피를 쓰고 출력으로 A 정규화 → \(q'''_{max}=\frac{1.16PE_d}{Ha^2nE_R}\).
  3. 봉 하나의 총발열 \(q_r=\frac{2.32PE_d}{nE_R}J_0(2.405r/R)\).
  4. 붕괴열 : 무한 운전 곡선 (Fig. 8.3)을 써서 \(P(t_s)-P(t_0+t_s)\) — 유한 운전 기간 보정.

시험 포인트

정지 직후 ≈ 6 – 7 %, 1시간 ≈ 1.5 %, 1일 ≈ 0.5 %. 반사체 · 비균일 농축으로 분포를 평탄화하면 같은 q'''max 로 더 큰 출력. 붕괴열은 냉각재 상실 사고(LOCA) · 사용후핵연료 저장조 설계의 근거.

§8.3전도에 의한 열전달연료 → 간극 → 피복의 온도 강하
쉽게 말하면

연료 중심에서 생긴 열은 연료 → 간극(연료와 피복관 사이 틈) → 피복관을 차례로 지나 밖으로 나와요. 각 층은 전기회로의 저항처럼 온도 강하를 만들고, 그 강하가 직렬로 더해져요. UO₂는 열을 정말 못 전하는 세라믹이라 연료 안에서만 1,000 °C 넘게 떨어져요. 신기하게도 연료 안 온도 강하는 q'/(4πk)로 반지름과 무관해서, 설계 한계를 '봉 1 m당 출력(선출력 q')'으로 정해요.

유도 흐름

  1. Fourier 법칙 \(\mathbf q''=-k\nabla T\) + 에너지 보존 → \(\nabla^2T+\frac{q'''}{k}=0\).
  2. 원통 연료봉 (q''' 균일, 중심 대칭) : \(T(r)=T_m-\frac{q'''r^2}{4k_f}\) (포물선).
  3. 표면 r = a 에서 \(T_m-T_s=\frac{q'''a^2}{4k_f}=\frac{q'}{4\pi k_f}\) (q' = πa²q''').
  4. 피복 (발열 없음) : 로그 분포, \(\Delta T_c=\frac{q'\ln(1+b/a)}{2\pi k_c}\). 간극 : \(\Delta T_g=\frac{q'}{2\pi a h_{gap}}\).
  5. 직렬 열저항으로 합침 — 전기회로 유사.

핵심 결과

$$T_m-T_b=q'\left[\frac{1}{4\pi k_f}+\frac{1}{2\pi ah_{gap}}+\frac{\ln(1+b/a)}{2\pi k_c}+\frac{1}{2\pi(a+b)h}\right]$$

평판 연료 (반두께 a) : \(T_m-T_s=\frac{q'''a^2}{2k_f}\).

시험 포인트

UO₂ 는 kf ≈ 2 – 3 W/m·K 로 매우 낮아 온도 강하의 대부분이 연료 안에서 일어납니다 (Ex. 8.4 : 98 %). k 가 온도 의존이면 \(\int_{T_s}^{T_m}k\,dT=\frac{q'}{4\pi}\) (전도도 적분).

§8.4냉각재로의 열전달h 상관식과 축방향 온도 분포
쉽게 말하면

피복관 표면에서 냉각수로 열이 넘어가는 건 대류예요. 뜨거운 국을 후후 불면 빨리 식듯이, 유체가 빨리 흐를수록 열전달계수 h가 커져요. 냉각수는 아래에서 위로 흐르며 계속 데워지기 때문에, 열이 가장 많이 나는 곳은 노심 중앙이지만 피복관이 가장 뜨거운 곳은 중앙보다 조금 위쪽(하류)이에요.

무엇을 배우나

피복 표면 → 냉각재는 대류입니다. h 는 유동 · 물성 · 형상에 따라 실험 상관식으로 구합니다. 비원형 채널은 등가직경 De = 4 × 유동단면적 / 젖은둘레 를 씁니다.

상관식

  • Dittus–Boelter (관 내 난류) : \(\text{Nu}=0.023\,\text{Re}^{0.8}\text{Pr}^{0.4}\).
  • Weisman (봉다발, 사각 배열) : \(\text{Nu}=C\,\text{Re}^{0.8}\text{Pr}^{1/3}\), \(C=0.042\,P/D-0.024\).
  • 액체금속 (Pr ≪ 1) : Nu = A + B Pen 형태 — 전도가 커서 Pe 의존.

축방향 분포

$$T_b(z)=T_{b,in}+\frac{q'''_{max}V_f}{\pi wc_p}\left[1+\sin\frac{\pi z}{H}\right],\qquad T_c(z)=T_b(z)+\frac{q''(z)}{h}$$

냉각재 온도는 단조 증가, 열속은 cos → 피복 · 연료 최고온도 위치는 중앙보다 하류 (Ex. 8.7).

시험 포인트

Re, Pr 를 계산해 상관식 적용 범위(난류 Re > 10⁴)를 확인하는 단계를 빠뜨리지 마세요. dTc/dz = 0 으로 최대 위치 zc 를 구하는 문제.

§8.5비등 열전달과 임계열속비등곡선, 핵비등, DNB
쉽게 말하면

냄비에 물을 끓일 때 바닥에서 작은 기포가 생겼다 떨어지는 단계(핵비등)는 열이 아주 잘 빠져요. 그런데 열을 너무 세게 가하면 기포가 합쳐져 바닥을 증기막이 덮어 버리고, 증기는 열을 잘 못 전하니 바닥 온도가 순식간에 치솟아요. 그 경계의 열속이 임계열속(CHF)이에요. 원자로는 열속이 핵분열로 정해져 있어서, CHF를 넘으면 피복관 온도가 수백~수천 도 뛰어 손상될 수 있어요.

비등곡선 (풀 비등, 벽 과열도 ΔTsat 에 따라)

  1. 자연대류 → 핵비등 (기포가 벽에서 생겨 h 가 매우 큼, 과냉 → 포화).
  2. 열속 최대점 = 임계열속 q''c (CHF, DNB, burnout).
  3. 천이비등 (불안정) → 막비등 (증기막이 단열재 역할).
  4. 열속 제어계(원자로)에서는 CHF 를 넘는 순간 천이 구간을 건너뛰어 막비등으로 점프 → 벽온도 급상승.

상관식

$$\text{Jens–Lottes : }T_c-T_{sat}=60\left(\frac{q''}{10^6}\right)^{1/4}e^{-P/900}\quad(\text{°F, psia})$$
$$\text{Bernath : }q''_c=h_c(T_{wc}-T_b),\ \ T_{wc}=102.6\ln P-\frac{97.2P}{P+15}-0.45v+32$$

BWR 은 건도 x 가 크므로 GE 상관식 (q''c vs 건도 · 질량속), PWR 은 W-3 등을 씁니다.

시험 포인트

PWR = 과냉 비등의 DNB, BWR = 고건도 환상류의 dryout — 메커니즘이 다름. 비등곡선 그림의 각 구간 이름과 원자로가 운전되는 구간(핵비등 이하)을 표시하는 문제.

§8.6원자로 열설계한계 → 고온채널 인자 → 노심 크기
쉽게 말하면

열설계는 '가장 나쁜 곳'을 기준으로 해요. 평균 연료봉이 아니라 가장 뜨거운 채널의 가장 뜨거운 지점이 한계(연료 융점, 최소 DNBR)를 지켜야 해요. 평균 대비 최고가 몇 배인지가 고온채널 인자 F. 그래서 순서는 한계 → 허용 최대 열속 → ÷F 로 평균 열속 → 총출력 ÷ 평균 열속 = 전열면적 → 연료봉 개수로 이어져요.

설계 한계

  • 연료 중심이 녹지 않을 것 (UO₂ 2,760 – 2,815 °C).
  • 최소 DNBR 이상 (PWR 1.3, BWR 1.9 수준) — 과도 상태 포함.
  • 피복 온도 · 산화 제한.

고온채널 인자

$$F_q=\frac{q''_{max}}{q''_{av}}=F_N\cdot F_E,\qquad F_{E,x}=1+\frac{3\sigma_x}{\bar x}$$

FN : 핵적(중성자속 분포) 피킹, FE : 제작 공차 · 유동 편차 등 공학적 불확실성 (3σ 기준).

설계 순서 (Ex. 8.12)

  1. CHF 와 MDNBR 로 허용 q''max 결정.
  2. q''av = q''max/F 로 평균 열속.
  3. 필요 전열면적 A = P/q''av → 봉 수 n = A/(πDH).
  4. 선출력 · 중심온도 검증 → 필요하면 봉 직경 · 피치 조정.

시험 포인트

F 가 크면(출력 분포가 뾰족하면) 같은 출력에 더 많은 봉 · 더 큰 노심이 필요 → 6장의 평탄화(반사체, 농축도 구역, 제어봉 배치)가 경제성으로 연결됩니다.

실험실 1 · 연료봉 단면 온도

직렬 열저항 : 연료 → 간극 → 피복 → 냉각재 막
먼저 예측

선출력 q' 은 그대로 두고 냉각재 열전달계수 h 를 2배로 올리면 연료 중심온도는?

가장 큰 온도 강하는 연료 내부의 q'/(4πkf)인데, 이건 h와 상관없어요. h는 맨 바깥 '막' 온도 강하만 줄여요. 반대로 kf 나 hgap 을 바꿔 보면 중심온도가 훨씬 크게 움직이는 걸 볼 수 있어요.

스스로 점검

Q1 연료봉을 가늘게 하면 중심온도가 낮아질까?
같은 선출력 q' 이라면 연료 내부 ΔT = q'/(4πkf) 는 반지름과 무관합니다. 가는 봉은 같은 총출력을 더 많은 봉에 나눠 q' 을 낮출 수 있어서 유리한 것입니다.
Q2 원자로가 '열속 제어계'라서 CHF 가 위험한 이유는?
열속이 핵분열로 정해지므로, CHF 를 넘어 증기막이 생기면 h 가 급감해도 열속은 그대로 → 벽온도가 비등곡선의 C 에서 E 로 수천 도 점프합니다.
Q3 피복관 최고온도가 노심 중앙보다 위쪽에서 생기는 이유는?
냉각재 온도 Tb 는 중앙을 지나서도 계속 오르고, 열속 q'' (∝ cos) 은 중앙 근처에서 천천히 감소합니다. 두 효과의 균형점이 하류에 있습니다 (Example 8.7 : +2.7 ft).
