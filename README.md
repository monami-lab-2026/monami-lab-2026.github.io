# Hee Sang Yoo Academic Homepage

This folder contains a single-page, GitHub Pages-ready academic homepage.

## Files

- `index.html`: complete homepage with embedded CSS and minimal JavaScript
- `figure/PHOTO.jpg`: profile photograph expected by the page

## Install into the existing GitHub Pages repository

1. Replace the current repository-root `index.html` with this `index.html`.
2. Keep the existing `figure/PHOTO.jpg` file at the same path.
3. Commit and push to the branch used by GitHub Pages.
4. Open the website and hard-refresh the browser (`Ctrl+F5`).

## Important edits

Search the HTML for these items and update them when needed:

- CEA position and dates
- Current research description
- Publication list
- Google Scholar, LinkedIn, and CV links
- Contact text
